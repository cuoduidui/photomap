# PhotoMap 旅行游记功能 — 产品需求文档 (PRD)

## 1. 功能概述

### 1.1 背景
用户在五一假期去上海旅游，拍了几百张照片。当前地图按地点分组，但无法体现"这是一次连续的旅行"。用户希望：
- 地图分组时，同一地点 + 连续时间段的照片归为一次"旅行"
- 可为每次旅行编写或 AI 生成游记文章
- 几年后翻看时，能快速回忆当时的经历

### 1.2 核心价值
将零散的照片按「时空」维度组织成有意义的旅行记忆，配合文字叙述，形成可回顾的游记。

### 1.3 用户场景
```
导入 500 张照片 → 系统自动识别出"5月1日-5月5日 上海"是一次旅行
→ 用户点击该旅行 → 查看地图轨迹和照片
→ 点击"生成游记" → AI 根据照片元数据生成初稿
→ 用户编辑修改 → 保存游记
→ 3年后打开 → 完整回忆当年旅行
```

## 2. 详细需求

### 2.1 时空聚类算法

#### 2.1.1 聚类规则
- **时间窗口**：连续 7 天内的照片视为同一次旅行的时间范围
- **空间阈值**：同一城市（province + city）内的照片归为一组
- **最少数目**：一组旅行至少包含 5 张照片（避免零散照片形成旅行）
- **时间间隔**：相邻两张照片间隔超过 48 小时则切断旅行（即使同城）

#### 2.1.2 聚类流程
```
1. 取所有有坐标 + 拍摄时间的照片，按时间排序
2. 遍历照片，判断是否与当前组属于同一旅行：
   - 同城市 AND 时间间隔 < 48h → 加入当前组
   - 不同城市 OR 时间间隔 > 48h → 开始新组
3. 过滤掉照片数 < 5 的组
4. 为每组生成旅行信息：标题、时间范围、地点、照片数
```

#### 2.1.3 旅行标题自动生成
- 格式：`{城市名}之旅` 或 `{起始月日}-{结束月日} {城市名}`
- 示例：`5月1日-5月5日 上海之旅`
- 如跨多个城市：`华东五市之旅（上海→杭州→苏州）`

### 2.2 数据库设计

#### 2.2.1 新增 `trips` 表
```sql
CREATE TABLE trips (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,           -- 旅行标题
    start_date TEXT,               -- 开始日期 (ISO 8601)
    end_date TEXT,                 -- 结束日期
    cover_photo_id TEXT,           -- 封面照片 ID
    city_names TEXT,               -- 涉及城市 JSON array
    province_names TEXT,           -- 涉及省份 JSON array
    photo_count INTEGER DEFAULT 0, -- 照片数量
    journal_text TEXT,             -- 游记正文 (Markdown)
    journal_type TEXT,             -- 'manual' | 'ai_generated' | 'ai_edited'
    created_at TEXT,               -- 创建时间
    updated_at TEXT                -- 更新时间
);
```

#### 2.2.2 `photos` 表扩展
```sql
ALTER TABLE photos ADD COLUMN trip_id TEXT REFERENCES trips(id);
```
- 导入或重新聚类时自动填充 `trip_id`
- 照片可手动从一组移动到另一组

### 2.3 地图分组增强

#### 2.3.1 旅行分组标记
- 地图缩放级别 ≤ 8（省级）时，按旅行分组显示
- 每个旅行显示为一个聚合标记，包含照片数
- 标记样式区别于普通地点标记（旅行图标 + 日期范围）

#### 2.3.2 旅行轨迹线
- 点击旅行标记 → 显示该旅行的照片轨迹
- 用折线连接按时间排序的照片位置点
- 轨迹点大小表示照片密度

#### 2.3.3 时间轴回放
- 点击旅行 → 可选择"时间轴回放"
- 按拍摄时间顺序逐张显示照片在地图上的位置变化
- 支持播放/暂停/调速

### 2.4 游记编辑器

#### 2.4.1 编辑器界面
- 左侧：照片缩略图列表（按时间排序）
- 中间：Markdown 编辑器（支持实时预览）
- 右侧：地图（显示该旅行所有照片位置 + 轨迹线）
- 顶部：旅行标题、日期范围、城市信息

#### 2.4.2 编辑功能
- **手动编写**：支持 Markdown 语法
- **插入照片**：点击左侧缩略图插入到正文，显示为 `![描述](photo_id)`
- **插入位置**：可插入当前位置标签（自动渲染为地名）
- **插入日期**：可插入照片拍摄时间
- **自动保存**：每 3 秒自动保存草稿
- **字数统计**：实时显示正文字数

#### 2.4.3 AI 游记生成

**生成策略**：
1. 收集旅行的元数据：
   - 时间范围、天数
   - 涉及城市和地点
   - 照片数量、拍摄时间分布
   - 相机型号、焦距分布（推测拍摄类型）
   - 有无人物标签
2. 调用 AI 模型生成游记初稿
3. 生成结果包含：
   - 标题建议（3 个选项）
   - 正文（800-1500 字）
   - 照片插入位置建议

**AI 模型接入**：
- 支持配置 API Key（OpenAI / 国内大模型如通义千问、文心一言）
- 可选择模型和生成长度
- 生成后用户可编辑修改

**Prompt 模板**：
```
你是一位旅行作家。根据以下旅行数据，写一篇 {length} 字的游记。

旅行信息：
- 时间：{start_date} 至 {end_date}（{days} 天）
- 地点：{cities}
- 照片数：{photo_count} 张
- 拍摄设备：{camera_models}
- 主要拍摄焦段：{focal_lengths}
- 人物标签：{person_tags}

要求：
1. 以第一人称写
2. 按时间线展开
3. 在合适位置标注 [插入照片: {photo_id}] 
4. 语言自然生动，有情感
5. 结尾有感想总结
```

### 2.5 旅行列表页

#### 2.5.1 列表展示
- 卡片式布局，每张卡片显示：
  - 封面照片（旅行中第一张有代表性的照片）
  - 旅行标题
  - 日期范围 + 天数
  - 城市标签
  - 照片数量
  - 游记状态（未写/已写/AI生成）
- 按时间倒序排列
- 支持按年份、城市筛选

#### 2.5.2 操作
- 点击卡片 → 进入旅行详情页（地图 + 照片 + 游记）
- 长按/右键 → 编辑标题、删除旅行、重新聚类
- 支持手动创建旅行（选择照片组成新旅行）

### 2.6 旅行详情页

#### 2.6.1 布局
```
┌─────────────────────────────────────────────────┐
│  ← 返回    5月1日-5月5日 上海之旅    [编辑游记]  │
├──────────┬──────────────────────────────────────┤
│          │  地图（轨迹 + 照片标记）              │
│  照片    │                                       │

│  (缩略   │──────────────────────────────────────│
│  图)     │  游记预览 / 编辑器                    │
│          │                                       │

```

#### 2.6.2 功能
- 地图显示旅行中所有照片位置和轨迹线
- 点击地图标记 → 左侧照片列表滚动到对应照片
- 点击左侧照片 → 地图定位到照片位置
- 游记区域支持展开编辑
- 时间轴回放按钮

### 2.7 UI 入口

- 左侧面板新增「旅行」标签页（图标：飞机/路线）
- 点击进入旅行列表
- 也可在「智能影集」中展示旅行分组

## 5. 非功能需求

- **性能**：10,000 张照片聚类时间 < 2 秒
- **存储**：游记文本存储在 SQLite，不额外增加文件
- **兼容**：不破坏现有照片导入、地图、标签等功能
- **隐私**：AI 生成时只发送元数据，不上传照片内容
- **离线**：游记编辑器离线可用，AI 生成需联网
